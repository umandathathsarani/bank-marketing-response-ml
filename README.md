# Bank Marketing Campaign Response Prediction

## Overview
This repository contains a professional end-to-end Machine Learning project to predict customer response to bank marketing campaigns. It is designed to help the bank prioritize marketing resources based on historical evidence.

## Business Problem
A bank wants to improve the effectiveness of its marketing campaigns by identifying customers who are more likely to respond positively to an offer, allowing campaign resources to be prioritised using historical evidence.

## Objective
Predict whether a customer will respond positively to the bank's marketing campaign using available customer, previous-contact, and current-campaign information.
